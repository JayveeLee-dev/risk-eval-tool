# risk-eval-tool

建材应收账款风控AI Agent 的配套批量评测工具：批量调用Agent对测试案例评分，自动计算等级判定准确率 / 高危漏报率 / 节点分一致率。

## 项目背景

风控Agent采用三节点评分架构：

- **项目风险评估（权重40%）**：四维度加权（单位关系40%/权限30%/直签20%/资金10%）+ 4条一票否决红线（讨薪闹事/停工烂尾拖欠/质量安全事故/工期严重延后，命中直接≥85判高）
- **企业信用评估（权重40%）**：严格区分"被执行人"（+40~60分补偿区间，判中）与"失信被执行人"（一票否决），含司法记录归因原则（仅本客户记录生效）
- **合同风险扫描（权重20%）**：账期>60天=高风险档，未指定签收人=中档

本工具用于验证AI评估与业务专家判断的一致性，并驱动产品迭代。

## 评测结果（n=15，真实业务脱敏案例，两轮标注协议）

| 指标 | 结果 |
|---|---|
| 综合等级判定准确率 | **86.7%（13/15）** |
| 高危漏报 | 2例（1例阈值边界抖动，1例合同节点盲区，见下） |
| 综合分平均绝对误差 | 9.4分（首轮16.35，归因后显著下降） |

**两轮标注协议**：专家初标 → 跑评测 → 用Agent的联网发现回填复核专家标注（专家不可能比联网查询信息更全） → 重跑对比。首轮66.7%的分歧中3/5源于标注完备性而非模型错误，修正后分差<3分。

## 已知问题与迭代建议（评测驱动，按优先级）

1. **P0 合同节点无法感知"无书面合同"**：节点输入仅账期+签收人，真实业务最致命风险不可见，致1例高危漏报（约70分风险贡献缺失）→ v2：增加合同存在性字段或接入合同文本扫描
2. **P1 公开检索存在业界信息盲区**：2例"联网查不到≠无风险"实证（未公开舆情不可达）→ v2：RAG双源检索（联网搜索+行业知识库沉淀）
3. **P1 综合分65-75阈值敏感区**：边界案例±3分节点差即翻转等级 → v2：设人工复审带
4. **P2 报告量化声明缺依据**："预期坏账率<5%"类表述改为区间或删除
5. **P3 利息/律师费条款规则无输入通道**：明确触发条件或下线

## 开发过程备注

本工具与Agent本体均采用AI Coding开发（Prompt驱动生成+人工逐段验收）。
排查记录：接口500错误 → 读响应体定位 → 最小化测试 → 发现"工作流未部署"（AI曾给出编造域名，经字符重排比对识别） → 部署修复后全链路跑通。

## 使用

1. `pip install -r requirements.txt`
2. 按格式准备案例（见 demo_input.xlsx，12字段，英文键名）
3. 修改 eval_v2.py 开头的服务地址与认证信息
4. `python eval_v2.py`
